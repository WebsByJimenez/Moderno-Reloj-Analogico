# 🕰️ Tempo - Reloj Analógico Elegante

Un reloj analógico minimalista desarrollado con tecnologías web estándar (HTML, CSS y JS). El diseño combina una estética visual oscura y refinada inspirada en la alta relojería con un sistema de posicionamiento y movimiento basado en precisión matemática.

## 🚀 Características Clave

- **Distribución Matemática Circular:** Los 12 números del reloj se posicionan de manera dinámica y automática usando variables CSS y la función `calc()`.
- **Precisión y Fluidez:** Las manecillas se actualizan en tiempo real mediante un intervalo optimizado en JavaScript. La aguja de las horas y los minutos se desplaza de forma continua y proporcional al avance del tiempo, evitando saltos bruscos.
- **Arquitectura Limpia:** Uso de variables nativas CSS (`:root`) para una gestión eficiente de la paleta de colores y mantenimiento ágil.
- **Diseño Responsivo:** Interfaz completamente fluida y centrada gracias al uso de Flexbox y transformaciones de CSS.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración semántica, limpia y accesible (`<main>`, `aria-label`).
- **CSS3:** Posicionamiento absoluto, transformaciones (`rotate`, `translate`), funciones matemáticas y variables de entorno.
- **JavaScript (ES6+):** Manipulación del DOM mediante el objeto nativo `Date` y temporizadores optimizados.
